# Family Habits

Простое Android-приложение для семейного трекера привычек.

## Возможности
- Просмотр привычек семьи
- Добавление привычки и выбор участника
- Отметка выполнения
- Удаление привычек
- Подсчёт дневного прогресса
- Локальное хранение в SQLite

## Технологии
Kotlin, Jetpack Compose, SQLiteOpenHelper, Android SDK.

## Запуск
1. Откройте папку проекта в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Создайте Android Virtual Device (Device Manager → Create Device).
4. Нажмите Run.

## Сборка APK
Build → Build Bundle(s) / APK(s) → Build APK(s).
APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
